# 원신 얼음여왕·다니카 뽑기 계획: 명함·전무 확보 시나리오

이 문서는 2026년 11월 15일을 기준으로 원신의 **다니카 명함(캐릭터 1개), 얼음여왕 명함(캐릭터 1개), 얼음여왕 전용 무기 1개**를 확보하려는 재화 계획이다. 캐릭터의 추가 돌파나 무기 제련은 우선 목표에서 제외한다. 출시 일정, 기원 규칙, 복각 여부와 보상은 바뀔 수 있으므로 수치는 당시 계획의 스냅샷으로 읽어야 한다.

## 목표와 보유 재화

| 항목 | 상태 |
| --- | --- |
| 보유 원석 | 8,000개 |
| 뒤얽힌 인연 | 5개 |
| 캐릭터 이벤트 기원 | 40스택, 반천장(다음 픽업 5성 확정 아님) |
| 캐릭터 픽뚫 이력 | 1회, 별빛 포착 관련 누적 이력으로 진술 |
| 무기 이벤트 기원 | 40스택 |
| 예정 원석 구매 | 8,800개씩 2회, 총 17,600개 |
| 최종 목표 | 다니카 명함 + 얼음여왕 명함 + 얼음여왕 전무 1개 |

원석 160개를 기원 1회로 계산하면, **현재 원석 8,000개 = 50뽑**, 보유 인연 5개를 합쳐 **55뽑**이다. 추가 구매 17,600개는 **110뽑**이다. 따라서 미래 획득분을 빼고도 **165뽑**을 준비할 수 있다. 캐릭터 40스택과 무기 40스택은 이미 진행한 천장 횟수이므로 165뽑에 더할 수 있는 인연이 아니다.

## 앞으로 획득할 재화의 범위

공월, 이벤트, 일일 의뢰, 주기적으로 초기화되는 콘텐츠, 교환 재화를 포함해 얼음여왕 픽업 종료 시점까지 **45~70뽑**을 추가 획득하고 기원 페이백으로 **약 5~10뽑**을 환급받는 시나리오를 가정한다. 이미 받은 보상은 중복 집계하지 않으며, 실제 일정과 플레이·과금 상태가 확인되지 않았으므로 확정 수량이 아니다.

| 항목 | 환산 뽑기 |
| --- | ---: |
| 기존 보유 원석·인연 | 55 |
| 8,800원석 × 2회 | 110 |
| 미래 활동 보상(가정) | 45~70 |
| 스타라이트 페이백(가정) | 5~10 |
| **가정상 총 확보 가능량** | **215~245** |

여기서 **230뽑**은 중간 시나리오로 사용한다. 미래 보상의 실제 획득 가능 여부와 5성·4성 결과에 따라 페이백이 달라지므로, 위 범위는 보장되는 재화가 아니다.

## 세 가지 목표를 모두 얻을 가능성

당시 계획에서 제시된 확률 추정은 다음과 같다. 단, **시뮬레이션의 실행 코드, 확률 테이블, 표본 데이터가 남아 있지 않아 독립 검증할 수 없는 비공식 근사치**이다. 특히 별빛 포착의 개인별 누적 적용, 정확한 무기 기원 규칙, 캐릭터별 출시 순서·기간에 따라 결과가 달라질 수 있다. 이를 공식 확률이나 보장 확률로 인용해서는 안 된다.

| 총 확보 뽑기 | 다니카 명함 + 얼음여왕 명함 + 얼음여왕 전무 추정 확률 |
| --- | ---: |
| 215 | 55.5% |
| 230 | 65.7% |
| 245 | 71.2% |

위 표는 **해당 목표의 성공 가능성을 탐색하기 위한 과거 응답의 수치**로 보존한다. 실제 지출 의사결정에는 기원 규칙을 다시 확인하고 재현 가능한 계산을 실시할 필요가 있다.

## 뽑기 순서와 실패 시 대응

우선순위는 **다니카 명함 → 얼음여왕 명함 → 얼음여왕 전무**로 설정한다. 목표 셋을 확보하고 남은 재화가 있을 때에만 얼음여왕 돌파에 도전한다.

첫째, 캐릭터 40스택에서 다니카의 명함을 노린다. 현재 '반천장'이므로 다음 5성이 반드시 픽업 캐릭터라는 뜻은 아니다. 픽뚫 이력 1회는 개인별 별빛 포착 규칙을 따로 확인해야 하며 곧바로 확정 픽업으로 간주할 수 없다.

둘째, 얼음여왕 명함을 확보한다. 명함을 획득하기 전에는 추가 돌파에 뽑기를 소비하지 않는다. 다니카에서 얼마나 소모했는지에 따라 무기 도전 가능 재화를 재산정한다.

셋째, 무기 기원의 현재 40스택을 활용해 얼음여왕 전용 무기를 목표로 한다. 무기 기원은 **5성 등장**과 **선택한 전용 무기 획득**이 다르며, 운명 포인트 등 픽업 보장 체계는 당시 실제 규칙을 재확인해야 한다. 서로 다른 기원 기간의 운명 포인트 이월 여부도 점검해야 한다.

만약 보유 뽑기가 계획보다 적어지면, 확률표의 중간값을 믿고 돌파에 먼저 투자하기보다 명함 확보를 우선하고 이후 전무 획득 가능성을 판단한다.

## 이 계산에서 구별해야 할 것

- **원석·인연**은 앞으로 사용할 수 있는 실제 재화이며, **스택**은 이미 누적된 기원 횟수다.
- **기원 5성 천장**과 **원하는 픽업 대상의 확정 획득**은 서로 다른 사건이다.
- **반천장과 픽뚫 이력**은 동의어가 아니다. 별빛 포착이 개입하면 별도의 조건 확인이 필요하다.
- **미래 보상과 스타라이트 페이백**은 계획 시점의 추정치이므로 실제 보유량으로 오해하지 않는다.
- **55.5~71.2%**는 검증된 수학적 결과가 아니라 당시 계산 결과의 기록이다. 정확한 확률 분석에는 해당 버전 기원의 명세와 재현 가능한 시뮬레이션이 필요하다.

## 계획의 결론

현재 보유 55뽑과 17,600원석 추가 구매 110뽑을 합치면 기본 재원은 165뽑이다. 향후 보상과 페이백을 가정한 215~245뽑 시나리오에서 **다니카 명함 + 얼음여왕 명함 + 얼음여왕 전무**를 최우선 목표로 삼는다. 얼음여왕 1·2돌은 이 목표가 충족된 후의 선택 사항으로 남긴다.

이 문서는 **2026-11-15 기준 계획이며, 공식 일정·보상량 및 근사 확률은 추가 검토 필요** 상태다.
