# CAMM2와 MRDIMM: PC와 서버 메모리가 진화하는 서로 다른 방향

RAM은 실행 중인 프로그램과 데이터를 임시로 보관하는 작업 공간이다. 저장장치(SSD)가 서류 창고라면 RAM은 책상에 펼쳐 둔 자료에 가깝다. RAM 용량이 부족하면 프로그램 전환과 대용량 작업이 느려질 수 있고, 메모리 대역폭이 부족하면 CPU가 데이터를 기다리는 시간이 늘어날 수 있다.

**CAMM2와 MRDIMM은 DDR6처럼 새로운 DRAM 세대를 가리키는 말이 아니다.** CAMM2는 메모리 모듈의 *모양·장착 방식·전기적 연결*을 바꾸는 규격이고, MRDIMM은 서버에서 *여러 메모리 랭크의 데이터를 다중화해 전송 대역폭을 높이는* 기술이다. 서로 경쟁하는 동일 범주의 제품이 아니라 해결하는 문제가 다르다.

## 1. 사용자가 알아야 할 기본 용어

- **RAM/DRAM**: 프로그램 실행에 사용하는 휘발성 주기억장치와 그 대표적인 반도체 기술.
- **DDR5**: DRAM의 데이터 전송 규격 세대. DDR5라고 해서 모듈 외형까지 하나로 정해지는 것은 아니다.
- **DIMM**: 데스크톱 등에 쓰는 길쭉한 메모리 모듈 형태. **SO-DIMM**은 주로 노트북용 소형 모듈이다.
- **LPDDR5X**: 저전력 중심 DRAM 기술. 얇은 노트북에서는 메인보드에 납땜되어 교체할 수 없는 경우가 많았다.
- **MT/s**: 초당 수백만 번의 데이터 전송을 뜻하는 단위. MHz(클럭)와 혼동하지 않아야 한다.
- **대역폭**: 초당 전송할 수 있는 데이터량. **지연시간**은 특정 요청에 응답하기까지 걸리는 시간이다. 둘은 다른 지표다.
- **채널**: CPU 메모리 컨트롤러와 메모리가 통신하는 독립적인 데이터 경로.
- **랭크(rank)**: 함께 동작해 일정 폭의 데이터를 제공하는 DRAM 칩들의 논리적 집합. 랭크 수와 채널 수는 같지 않다.

예를 들어 메모리 용량 32GB는 책상 크기, 대역폭은 초당 자료를 옮기는 속도, 지연시간은 자료를 요청한 뒤 첫 자료를 받기까지의 대기시간에 비유할 수 있다. 용량이 두 배라고 대역폭도 두 배인 것은 아니다.

## 2. CAMM2: 메모리를 꽂는 방식을 바꾸다

**CAMM2(Compression Attached Memory Module 2)**는 기존 DIMM처럼 긴 슬롯에 비스듬히 끼우는 대신, 평평한 모듈을 메인보드의 압착식 접점 위에 놓고 고정하는 방식이다. JEDEC 표준으로 DDR5 기반 CAMM2와 LPDDR5/LPDDR5X 기반 CAMM2를 다룬다. 초기 독자 규격 CAMM과 표준화된 CAMM2도 구별해야 한다.

### 사용자가 체감하는 장점

1. **얇은 설계**: 메모리 장착 높이와 공간을 줄여 얇은 노트북이나 소형 시스템의 설계 여지를 늘린다.
2. **교체 가능성**: 특히 LPCAMM2는 기존에 납땜되는 일이 많았던 LPDDR 계열 메모리를 교체 가능한 모듈로 구현한다.
3. **고속 신호 설계**: CPU와 메모리 사이 배선을 짧고 단순하게 설계할 여지가 있어 고속 전송에 유리할 수 있다.
4. **통합 구성**: 제품 설계에 따라 모듈 하나로 넓은 메모리 인터페이스를 제공할 수 있다. 단, '모듈 하나=항상 모든 PC에서 듀얼채널'이라는 뜻은 아니다.

### CAMM2와 LPCAMM2는 같은가?

**CAMM2**는 규격 계열을 가리키며 **LPCAMM2**는 그중 LPDDR5/5X를 사용하는 구현을 통상 지칭한다. DDR5 CAMM2와 LPDDR 계열 CAMM2는 전기적 핀 배치와 플랫폼 요구가 다르므로 무조건 교환해 사용할 수 없다. 기기 제조사의 지원 목록을 확인해야 한다.

### 한계

새 규격이므로 메인보드와 노트북이 처음부터 지원해야 한다. 기존 DDR5 DIMM 슬롯에 CAMM2를 직접 꽂을 수 없다. 제품별 가격·유통·업그레이드 가능 용량에도 차이가 있다. **같은 DRAM 속도·타이밍·채널 구성이라면 CAMM2라는 이름만으로 게임 FPS가 자동 상승하지 않는다.**

## 3. MRDIMM: 서버가 데이터를 더 빨리 공급하는 방식

**MRDIMM(Multiplexed Rank DIMM)**은 서버용 DDR5 메모리 모듈의 고대역폭 기술이다. CPU 코어 수가 늘어나면 CPU가 한꺼번에 요구하는 데이터도 많아진다. RAM 용량만 늘려서는 이 병목을 해결하기 어렵다.

일반적인 RDIMM은 메모리 랭크를 사용하지만 외부 인터페이스로 전달하는 데이터 속도에는 제약이 있다. MRDIMM은 모듈 내부에 **데이터 다중화 버퍼(MDB)**와 이를 조정하는 **제어 로직(MRCD)**을 사용해 여러 랭크의 데이터를 결합·다중화하여 CPU와의 전송 속도를 높인다.

단순화한 흐름은 다음과 같다.

```text
일반 RDIMM
CPU 메모리 컨트롤러 ←→ RDIMM ←→ DRAM 랭크

MRDIMM
CPU 메모리 컨트롤러 ←→ [다중화 버퍼·제어 회로]
                               ↙          ↘
                         DRAM 랭크 A   DRAM 랭크 B
```

두 랭크가 내부에서 데이터를 공급하고 버퍼가 이를 고속 외부 링크에 맞춰 전달하는 것이 핵심이다. 이는 **용량이 두 배가 된다**거나 **모든 프로그램이 두 배 빨라진다**는 뜻이 아니다. 메모리 대역폭에 제한된 작업에서 특히 유용하며 CPU·메인보드·BIOS의 지원이 필요하다.

### RDIMM, MCRDIMM, MRDIMM의 관계

**RDIMM**은 서버에서 명령·주소 신호를 등록·완충하는 전통적인 모듈이다. **MCRDIMM(Multiplexed Combined Rank DIMM)**은 특정 서버 플랫폼에서 사용된 명칭으로 MRDIMM과 함께 설명되는 경우가 있다. 다만 제품별 구현과 JEDEC 표준화 세대는 구별해야 한다. 같은 명칭처럼 보이더라도 서버의 호환성 목록을 확인하지 않고 서로 교환할 수 있다고 판단해서는 안 된다.

## 4. 핵심 비교

| 항목 | CAMM2 | MRDIMM |
| --- | --- | --- |
| 핵심 목적 | 모듈 장착 구조·공간·신호 경로 개선 | 서버 메모리 대역폭 확대 |
| 주 사용처 | 노트북·소형 PC, 일부 데스크톱 | 데이터센터·서버 |
| 변화의 중심 | 물리적 폼팩터와 접점 | 랭크 다중화·버퍼·전송 구조 |
| 메모리 종류 | DDR5 또는 LPDDR5/5X 계열 | 주로 DDR5 서버 메모리 |
| 교체·확장 | 지원 기기에서 모듈 교체 가능 | 지원 서버에서 모듈 교체 가능 |
| 기대 효과 | 얇은 설계, 수리·업그레이드 가능성, 고속 설계 여지 | 메모리 집약적 작업의 처리량 향상 |
| 대표 제약 | 전용 커넥터·보드·제품 호환성 | CPU·서버 플랫폼·펌웨어 호환성 |
| 오해 | 새 DRAM 세대 또는 무조건 빠른 RAM | RAM 용량이나 모든 작업 속도를 자동 두 배로 만드는 기술 |

**비교의 핵심:** CAMM2는 '메모리를 어떻게 연결할까', MRDIMM은 '메모리에서 CPU로 데이터를 어떻게 더 많이 보낼까'에 답한다.

## 5. 실제 사용 시나리오

### 게임용 데스크톱

현재 DIMM 기반 PC에서 CAMM2로 바꾸려면 대체로 메인보드 플랫폼 자체가 달라져야 한다. 게임 성능은 모듈 이름보다 **실제 메모리 속도·타이밍·용량·채널 구성, CPU의 메모리 컨트롤러 및 게임 특성**에 따라 달라진다. MRDIMM은 일반 게임용 PC의 업그레이드 후보가 아니다.

### 얇은 노트북

기존 납땜 LPDDR 노트북은 메모리 증설이 어려운 경우가 많았다. LPCAMM2를 채택한 기기는 제품이 지원하는 범위에서 모듈 교체가 가능할 수 있다. 다만 노트북이 LPCAMM2를 사용한다는 사실과 **사용자가 임의 용량으로 업그레이드할 수 있다는 보장**은 다르다.

### 대규모 서버와 AI 워크로드

대량의 데이터를 CPU로 지속 공급하는 서버는 메모리 대역폭의 영향을 크게 받는다. MRDIMM은 이러한 상황에서 의미가 있다. 반대로 GPU 자체의 HBM 대역폭을 MRDIMM이 대체하는 것은 아니다. CPU 메모리 병목과 GPU 메모리 병목을 분리해 판단해야 한다.

## 6. 성능 수치를 읽는 법

이론 대역폭은 단순화하면 **전송률(MT/s) × 데이터 버스 폭(bit) ÷ 8**로 계산한다. 예를 들어 64비트 경로에서 6,400 MT/s라면 약 **51.2GB/s**이다. 실제 성능은 메모리 채널 수, 접근 패턴, 명령 오버헤드, CPU 지원 등에 따라 낮아진다.

MRDIMM의 고속 수치는 일반 RDIMM과 비교할 때 같은 CPU·채널 수·구성 조건에서 해석해야 한다. CAMM2의 '공간 절약 60%' 같은 수치도 제조사가 정한 비교 대상(모듈 면적, 장착 체적, SO-DIMM 개수)에 따라 달라지므로 모든 제품의 절감률로 일반화할 수 없다.

## 7. 구매·도입 전 확인 항목

- **PC·노트북**: 제조사가 DDR5 CAMM2인지 LPCAMM2인지 명시하는가? 최대 용량과 교체 가능 여부는 무엇인가?
- **서버**: CPU 모델이 MRDIMM을 지원하는가? 메인보드·BIOS·메모리 구성표(QVL)에서 검증되었는가?
- **성능**: 용량 부족이 문제인가, 대역폭 부족이 문제인가, 지연시간이 문제인가?
- **운영**: 가격·전력·발열·수급·유지보수와 기존 메모리 재사용 가능성을 확인했는가?

## 결론

CAMM2는 노트북의 **얇은 설계와 교체 가능한 고속 메모리**를 향한 변화이고, MRDIMM은 서버의 **메모리 공급 속도를 높이는 다중화 기술**이다. 두 기술은 모두 메모리 병목을 개선하려 하지만, 개선하는 층위가 다르다. 사용자에게 중요한 것은 규격 이름보다 **자신의 시스템이 무엇을 지원하고, 실제로 어떤 병목을 해결하는지**다.
