# 개인 프로젝트 콘텐츠 정리

2026년 11월 2일, 프로젝트 분류의 `pododala-project-structure` 문서 1편만 유지했다.

- 기존 원고 173개를 삭제했다. 미게시 원고도 포함한다.
- 삭제된 글의 manifest 항목, 별칭, 의미 관계, 달력 항목과 교차 연결 제안을 제거했다.
- 기존 글의 증보 장부, 정비 보고서와 원자료 기록을 정리하고 프로젝트 문서의 증보 장부는 유지했다.
- 메뉴·소개·프로젝트 문서에서 삭제된 글로 향하는 연결을 정리했다.
- 생성물은 스크립트로 다시 만든다. 삭제 전 원고는 Git 이력에 남는다.
